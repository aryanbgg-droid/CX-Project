# CX AI Project 🤖

Welcome to my CX AI Project!

This project was created to explore how **Artificial Intelligence and data analysis** can be used to understand customer experience and generate useful insights from customer-related data.

The goal of this project is to work with customer experience data and use AI-based techniques to process the information and identify meaningful insights.

I built this project as part of my learning journey and to get hands-on experience with **Python, AI, data processing, and project development**.
